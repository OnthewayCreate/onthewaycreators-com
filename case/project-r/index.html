Webサイトリニューアル

就労支援に関する複数のプロジェクトのブランディングを担当

Project R様

ご依頼の背景

Project R様は、就労に困難を抱える方々を支援する複数のプロジェクトを同時に展開されている団体です。各プロジェクトはそれぞれ異なる対象者・支援内容を持っており、これまでは案件ごとに個別のWebページを制作会社に発注していたため、デザインのトーンやナビゲーションの構造がばらばらになってしまっているという課題を抱えていらっしゃいました。利用者の方からも「同じ団体が運営しているとわかりにくい」というお声があり、団体全体としての信頼感を伝えにくい状態になっていました。

課題

複数プロジェクトの独自性を保ちながら、同じ団体が運営していることが一目でわかるようにブランドを統一する必要がありました。また、支援を必要とする方が迷わず自分に合ったプロジェクトへたどり着けるよう、情報設計そのものを見直すことも求められていました。

ご提案・制作内容

まず全プロジェクトに共通するロゴマークとカラーパレット、タイポグラフィのルールを策定し、「Project R」としての統一感のあるブランドガイドラインを作成しました。そのうえで、各プロジェクトのページはガイドラインの範囲内で個性を出せるよう、アクセントカラーや写真の使い方に幅を持たせる設計としています。トップページからは利用者の状況に応じて最適なプロジェクトへ案内する導線を新たに設計し、初めて訪れる方でも迷わず必要な情報にたどり着けるようにしました。

成果

リニューアル後は、複数のプロジェクトが同一団体によるものであることが視覚的に伝わりやすくなり、問い合わせ時に「どのプロジェクトの話か」を確認する手間が減ったとご好評をいただいています。また、支援を必要とする利用者の方からの直接のお問い合わせ数も増加し、団体全体の認知度向上にもつながりました。
